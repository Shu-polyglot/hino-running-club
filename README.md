# 日野ランニングクラブ

走ることをきっかけに、人とつながる。日野ランニングクラブの公式サイトです。

## [サイトを開く →](https://shu-polyglot.github.io/hino-running-club/)

月の第2・第4土曜日、朝7:30から活動しています。

- 陸上未経験歓迎
- 一人参加OK
- 完全無料
- 集合場所：ふれあい橋

参加の申込みは、Instagram [@hinode_hashiro](https://www.instagram.com/hinode_hashiro/) へDMをお送りください。

## 開発

```bash
npm install
npm run dev
```

サイト本体はNext.jsで構築し、GitHub PagesとSitesで公開しています。
